# My Goals App

## Dependencies
SQLite 3.X.X and Apache HTTP Server 2.4 (not server software packages like XAMPP, which also includes it) must be installed and running in order for the application to work.

## Running the application
No special server configs are required, simply open http://localhost/my-goals-app/index.php in your browser and if SQLite and Apache Server are installed and running properly it'll work on its own.<br>
In order to **locally** access the application through a name-based address (without including *localhost* or the direct file path to index.php) check [this link](https://httpd.apache.org/docs/2.4/vhosts/examples.html) from the official Apache Server website that teaches how to do that, although that will only work in your local machine (the one holding the entries in the *hosts* file).
